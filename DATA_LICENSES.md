# Data and licenses

Sources used so far (Phase 1 inspection). Models are added when they are used.

| Source | Used for | License / terms | Status |
|---|---|---|---|
| Augmented Clinical Notes (AGBonnet/augmented-clinical-notes) | Main clinical text | MIT | Checked on dataset page |
| MedQuAD | Condition explanations | CC BY 4.0. Cite Ben Abacha & Demner-Fushman (2019); note changes | Checked (LICENSE file) |
| MeSH (NLM) | Term and procedure explanations | NLM terms: credit NLM, no implied endorsement, state MeSH version | Checked |
| RxNorm, RxClass (NLM RxNav APIs) | Drug names and classes | Free NLM APIs; credit NLM, no implied endorsement, state the RxNorm version | Checked. Lexicon built from RxNorm **02-Nov-2026** (IN, PIN, BN) |
| MedlinePlus Connect | "Learn more" links | Links only; drug monographs are copyrighted, never copied | Checked |
| ClinOCR-Bench | OCR test set | MIT | Checked on dataset page |
| Noisy Medical Document Images (Kaggle, devp1866) | OCR test set | CC BY-SA 4.0. Attribution required; adapted versions must use the same license | Checked on Kaggle page |
| FLORES+ | Hindi translation testing | Gated terms: no re-hosting, no training on it | Terms accepted |
| IN22-Conv (ai4bharat) | Hindi translation testing | CC BY 4.0. Attribution required | Checked on dataset page |

No real patient data is used anywhere in this project.
