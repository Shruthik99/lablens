# Organism species names: RxNorm IN/PIN/BN terms that are never themselves a medication.
#
# Unlike ambiguity_list.txt, no surrounding clinical context can rescue these -- a culture
# or sensitivity result naming a bacterium or fungus is never a prescribed drug. They are
# dropped outright, in every lexicon mode, before the index is built.
#
# Real drugs that are etymologically named after an organism (e.g. colistin) are
# deliberately absent: exclusion is by exact species name only, never a substring match.
